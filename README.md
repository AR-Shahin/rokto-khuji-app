# Rokto Khuji — Flutter app (donor & recipient)

Mobile app for the Rokto Khuji blood donation platform. It follows the Android UI design
(`Rokto Khuji — Android app UI` canvas) and talks to the Laravel API in
`../rokto-khuji` (`/api/v1`, Sanctum tokens — see `../rokto-khuji/docs/api/README.md`).

## 1. First-time setup

The Dart code is ready, but the Android/iOS project files are generated by Flutter:

```bash
cd rokto_khuji_app
flutter create . --org com.roktokhuji --project-name rokto_khuji_app --platforms android,ios
flutter pub get
```

`flutter create .` keeps the existing `lib/`, `test/`, `pubspec.yaml` and
`android/app/src/main/AndroidManifest.xml` (it already has the INTERNET permission and the
`<queries>` that phone/WhatsApp links need). If Flutter asks, do **not** overwrite them.

**iOS only** — add to `ios/Runner/Info.plist` (profile photo picker + links):

```xml
<key>NSPhotoLibraryUsageDescription</key>
<string>Choose a profile photo</string>
<key>LSApplicationQueriesSchemes</key>
<array><string>tel</string><string>https</string></array>
```

Requires Flutter **3.47+** (Dart 3.13+). The app uses `package:material_ui` (Material widgets moved out of
`package:flutter/material.dart` in Flutter 3.47) and `google_fonts` 9.

## 2. Run

```bash
# Live API (default)
flutter run

# Local Laravel (`php artisan serve`) from the Android emulator
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000/api/v1
```

For plain `http://` during local testing on Android, add
`android:usesCleartextTraffic="true"` to `<application>` in the manifest (remove it before release).

Build a release APK: `flutter build apk --release --dart-define=API_BASE_URL=https://roktokhuji.com/api/v1`

## 3. Folder structure

```
lib/
  main.dart                 Creates the API client, services and providers
  app.dart                  MaterialApp + AppRoot (splash → welcome → home)
  core/
    config/app_config.dart  API URL, timeouts, page size
    network/                ApiClient (Dio: token, language, errors) + ApiException
    storage/                TokenStorage (secure storage)
    l10n/                   tr('key') + Bangla/English text maps
    theme/                  Colors and fonts from the design guide
    utils/                  Formatters (Bangla digits, dates), validators, UI helpers
    widgets/                Shared widgets: buttons, fields, cards, badges, list states
  models/                   Plain Dart classes with fromJson (one per API resource)
  services/                 One class per API group (auth, donors, blood requests, ...)
  providers/                App-wide state: AuthProvider, MetaProvider, LocaleProvider
  features/
    auth/                   Splash, welcome, login, register (2 steps), forgot password
    home/                   Bottom navigation, dashboard, overdue-donation popup
    donors/                 Find donors, donor profile
    requests/               Create request, incoming / my requests, detail, sheets
    notifications/          Notification inbox
    profile/                Profile, edit, reviews, share story, settings, password
    shared/                 Area picker (search + drill down)
```

**How a screen gets data:** screen → service (`context.read<DonorService>()`) → `ApiClient`.
Screens never build URLs or parse JSON themselves.

**Errors:** every failed call becomes an `ApiException` with `message` (safe to show),
`code` (`email_not_verified`, `business_rule`, …) and `errors` (field → message, shown under inputs).
A `401` clears the token and goes back to Welcome automatically.

**Texts:** add a key to both `lib/core/l10n/strings_bn.dart` and `strings_en.dart`, then use `tr('key')`.

## 4. Features (same as the website)

- Register (blood group, role, area), login, forgot password, email verification banner
- Home: ready-to-donate switch, next donation date, stats, profile completion, new requests
- Overdue donation popup on every app open until completed or canceled
- Find donors by area (including sub-areas) and blood group, call / WhatsApp, donor profile + reviews
- Create a blood request (priority, bags, date/time) — auto escalation info is shown
- Donor: accept / decline / cancel acceptance / complete donation / rate requester
- Requester: see who accepted, call them, close with the donors who donated, rate donors, cancel
- Notifications inbox (opens the related request), mark all read, delete
- Profile edit (photo, phones, social links), my reviews, share your story, Telegram link
- Settings: Bangla/English, change password, log out from all phones, delete account
- Role rules: donor-only users do not see "+ Request"; recipient-only users do not see "Sent to me"
